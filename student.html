Notes

  • Integrity: We compute SHA-256(file) and compare it to the digest inside the CID to ensure the CID actually addresses your file.
  • On-chain docHash: The contract expects keccak256 of the canonical credential bytes. Use the default strategy unless you have a special reason.
  • Verify flow: A verifier fetches the file (or uses one provided), computes keccak256(bytes), and calls verifyCredential(credId, hash).
  • Security: Do not publish a long-lived Pinata JWT in client code. Use a server to upload and return the CID.
